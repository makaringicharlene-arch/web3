Birthday Piercing Date

To open the birthday website:
1. Save the ZIP attachment to your computer.
2. Extract the ZIP file.
3. Open index.html in Chrome or another web browser.

Keep all HTML, CSS, and JavaScript files together in the extracted folder.
Do not open index.html from inside the ZIP, and do not send index.html by itself.

The opening page has a five-question birthday quiz. Answering correctly opens
a Happy Birthday, Hitekani message and then the birthday message book. The quiz
is a playful client-side gate, not secure access control. Add messages in
messages.js. The envelope reveals a confetti surprise and a letter inviting her
to a piercing date at Pierced by Zulu on November 11.
